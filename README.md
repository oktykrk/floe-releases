# Floe for Mac

A native macOS window manager for a calmer workspace.

**Download Floe now and try it free for 7 days.**

[Download Floe 1.0 for Mac](https://github.com/oktykrk/floe-releases/releases/download/v1.0/Floe-1.0.dmg)

Purchasing and license activation are not available yet while Lemon Squeezy
approval is pending. Window management pauses after the trial; Settings remains
accessible. Reinstalling does not reset the trial.

This repository hosts Developer ID signed, Apple-notarized universal DMG downloads, release notes, and SHA-256 checksums. The application source is maintained privately.

Floe requires macOS 15 or later. The planned license is a one-time $9.99 USD purchase for two active Macs, with a 7-day app trial.

Open the DMG, drag Floe into Applications, launch it, and grant Accessibility
access. Screen Recording is optional, for window thumbnails.

Find version details and checksums in [Releases](https://github.com/oktykrk/floe-releases/releases). Purchasing will become available after merchant approval and verification of a new build configured for live licenses.
