# Floe for Mac

A native macOS window manager for a calmer workspace.

**Floe is preparing for launch. No public build is available yet.**

- [Product website](https://oktykrk.github.io/floe/)
- [Support and license help](https://oktykrk.github.io/floe/support.html)
- [Privacy policy](https://oktykrk.github.io/floe/privacy.html)
- [Terms](https://oktykrk.github.io/floe/terms.html)

At launch, this repository will host Developer ID signed, Apple-notarized universal DMG downloads, release notes, and SHA-256 checksums. The application source is maintained privately.

Floe requires macOS 15 or later. The planned license is a one-time $9.99 USD purchase for two active Macs, with a 7-day app trial.

Downloads will appear in [Releases](https://github.com/oktykrk/floe-releases/releases). Purchasing will become available after merchant approval and final release verification.
